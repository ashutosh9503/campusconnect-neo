# CampusConnect (CC_NEO)

CampusConnect is a full-stack campus social networking platform inspired by modern social media applications.  
It is designed for real-time interaction between students including posts, stories, messaging, groups, and events.

---

## 🚀 Features

- User authentication (Supabase)
- Create posts with images & videos
- Stories system (24h content)
- Real-time private messaging
- Groups & group discussions
- User profiles & search
- Notifications system
- Secure backend using Supabase
- Deployed with Vercel

---

## 🛠 Tech Stack

**Frontend**
- React (Vite)
- TypeScript
- Tailwind CSS

**Backend**
- Supabase (Postgres + Auth + Storage + Realtime)

**Deployment**
- Vercel

---
